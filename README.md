# react-native-new-confetti

Confetti package created with reanimated v3

## Installation

```sh
npm install react-native-new-confetti
```

## Usage

```js
import Confetti from 'react-native-new-confetti';

// ...

<Confetti
  numConfetti={80}
  run={confettiActive}
  onConfettiRunFinished={() => {
    setConfettiActive(false);
  }}
/>;
```
